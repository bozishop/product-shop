GitHub 同步

配置仓库后，可一键上传图片、一键发布 products.json（全站访客立即生效）

⚠️ 安全提醒：Token 类似仓库钥匙，仅保存在你自己浏览器的 localStorage，不会写入任何会公开的文件。请勿把 Token 发给他人。建议在 GitHub「Settings → Developer settings → Personal access tokens」中创建，勾选 repo 权限，并将其权限范围限定在本仓库（Fine-grained token 可选指定仓库）。
🔑 仓库配置
发布成功约 1 分钟内 GitHub Pages 站点即可看到新内容。若未配置，可走「数据管理」手动导出并 push。

♻️ 恢复与清空
「恢复默认」会丢弃本浏览器当前全部自定义数据；「清空商品」只清空商品列表。

修改密码

密码哈希随店铺数据保存：修改后本浏览器即时生效，一键发布后对所有设备生效

⚠️ 修改后需到「GitHub 同步」一键发布，其他设备/浏览器才会使用新密码；发布前它们仍使用旧密码（从未改过则为默认 admin123）。

新增商品

💡 从 Word/WPS 复制内容直接粘贴即可；若粘贴了 base64 图片，点工具栏「上传粘贴图片」可转存到仓库。
