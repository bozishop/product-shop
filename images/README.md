# images 图片目录

本目录存放站点使用的全部图片：

- `product-*.svg`：示例商品图（可替换为你的图片）
- `banner-*.svg`：示例轮播图
- `pay-code.svg`：示例收款码（**请替换为你的真实微信/支付宝收款码**）

## 上传方式

1. **后台自动上传（推荐）**：在后台「商品管理 / 站点设置」选择本地图片 → 点「上传到 GitHub 仓库」，图片会自动提交到本目录（`images/img_xxx.png` 命名），并自动以相对路径 `images/xxx.png` 写入数据。
2. **手动放置**：直接把图片文件放进本目录，然后在商品图片字段填写 `images/你的图片.png`。

> 使用相对路径的好处：无论是主站 `<用户名>.github.io` 还是项目站 `<用户名>.github.io/<仓库>`，图片都能正确显示。
